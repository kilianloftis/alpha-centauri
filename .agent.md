# Alpha Centauri Project - AI Development Instructions

You are assisting with development of **Alpha Centauri**, a C++ turn-based strategy game inspired by Sid Meier's Alpha Centauri.

## When working on this project

### Before starting work
1. Read the relevant diary files from `/memories/repo/`:
   - `progress-diary.md` - Current milestones and project phase
   - Component diary (e.g., `engine-diary.md`) for the system you're working on
   - Related component diaries if there are integration points

2. This gives you:
   - What's already been done
   - Architectural decisions and design rationale  
   - What's planned next
   - How components relate to each other

### While implementing
- Reference the diary to stay aligned with the design
- When you discover important patterns or make architectural decisions, note them
- When running into issues, check if they're documented in the diary

### After completing work
- Update the relevant diary with:
  - What was implemented
  - Any design decisions made or changed
  - Issues discovered or resolved
  - Updated "Next Steps" for future work

## Build and run

Use the `bd` build script:

```bash
# Configure
./bd configure

# Build
./bd build

# Configure and build in one step
./bd all

# Clean build directory
./bd clean

# Run (from build directory)
./build/alpha-centauri
```

Or use VS Code tasks: `Build (bd)`, `Build All (bd)`, `Configure (bd)`, `Clean (bd)`
