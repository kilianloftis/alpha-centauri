Keep architecture diagrams in `docs/architecture/` and update them when adding new components.

When adding a new component, follow these steps:

1. Analyze the existing architecture diagrams to understand the current structure.
2. Identify the appropriate location for the new component based on its functionality.
3. Update the architecture diagrams to reflect the new component.
4. Implement the component following the established patterns and conventions.

Keep a fine-grained architecture diagram for each major subsystem.

Keep a high-level architecture diagram that shows the overall structure of the system.

When modifying a component, if it affects the architecture, update the architecture diagrams accordingly.
